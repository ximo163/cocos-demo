# 接星星 StarCatcher（Cocos Creator 3.8 安卓小遊戲）

拖動籃子接住掉落的星星，避開炸彈。

- 引擎：Cocos Creator 3.8.6（TypeScript）
- 遊戲邏輯：`assets/scripts/StarCatcher.ts`（場景、相機、畫面全部由程式碼建立，美術用 Graphics 繪製）
- APK 由 GitHub Actions（`.github/workflows/build-android.yml`）在 Windows runner 上用 Cocos Creator 命令列建置，並自動發布到 Releases。

## 本地開啟
用 Cocos Creator 3.8.6 開啟此資料夾，選擇 `assets/scene/main.scene` 執行預覽。
